# DocRes boundary

DocRes is a planned research reference for document restoration tasks such as appearance enhancement, shadow handling, and cleanup. MP5 neither downloads nor vendors its code, weights, datasets, or training recipes.

The upstream code is recorded as an MIT-planned reference in the dependency register, but each release still requires an exact revision and license verification. Weights, dataset provenance, and any licenses inherited through training data are **audit-gated** and cannot be assumed from the repository code license. DocRes is therefore a future teacher/baseline candidate, not a Wellfriend production dependency.

MP6 is the earliest phase for an audited mobile/distillation decision. MP5 only supplies the artifact, provenance, and scalar restoration seams that such work must satisfy.
