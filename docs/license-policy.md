# License policy

Wellfriend Models is Apache-2.0. Direct dependencies, external model references, datasets, code, and weights need a recorded name/version/license/source/purpose/risk/consumer/scope before use.

GPL, AGPL, LGPL, non-commercial, research-only, custom, unclear, and unknown licenses are not accepted into production artifacts. A permissive code license does not prove weights or training-data rights: those are independently recorded and audit-gated. No third-party model code, datasets, or weights are vendored in MP5.

The dependency register records direct dependencies and planned references. Installation tooling may resolve transitive dependencies; releases must pin and audit the resolved environment before packaging a production model.
