# Roadmap

- **MP5:** reproducible schemas, synthetic fixtures, scalar baselines, registry/export validation.
- **MP6 (current):** device profiles, experimental mobile metadata, distillation/quantization/pruning reports, tiling, promotion gates, and synthetic ScanBench model reports.
- **MP7+:** artifact-compatible runtime adapters, audited tensor/ONNX candidates, governed calibration data, real-device validation, and independently reproduced benchmarks.

No roadmap item authorizes redistribution of restricted data or weights.
