# DocRes-Mobile boundary

DocRes-Mobile is a planned teacher/student research boundary, not an MP6 deliverable. The model registry has a document-restoration mobile family and scalar synthetic task seams for dewarping, deshadowing, appearance, deblurring, binarization, and end-to-end restoration.

DocRes remains audit-gated: code revision, weights, training data, licenses, and measurement evidence must be independently reviewed before any teacher/student experiment or artifact promotion. No DocRes code or weights are downloaded or vendored here.
